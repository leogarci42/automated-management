# CUCPP Language Features

## Features implemented

- `compute` (functions) 
- function parameters 
- `return` 
- variables / assignments (`x = 12`) 
- variable shadowing (`x2 = x1 - 1`) 
- `if` / `ifelse` 
- math subtraction (`-`) and addition (`+`) 
- math multiplication (`*`) 
- comparisons (`>`, `<`, `==`) 
- `print(var)` built-in 
- `while` loops (C-style)
- arrays, structs, pointers  (using `alloca` for now)


## Features not yet implemented
- `for` loops  (use a `while` loop for now).
- `break` 
- `continue` 
- complex math (`/`, `%`, bitwise) 
- logical conditions (`&&`, `||`, `!`) 
- explicit data types (`bool`, `char`, `string`, floats)  (All variables are 32-bit integers)
- multi-file handling
